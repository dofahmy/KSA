# نظام القوة النسبية لسوق المال السعودي — نسخة مستقلة

هذه **نسخة سعودية منفصلة**، وليست إعادة تسمية للمصرية. لا تستخدم قاعدة مصر أو جداولها أو خدماتها. 

## الخدمات المقترحة على Railway
1. PostgreSQL جديدة: `saudi-postgres` (مستقلة عن Postgres مصر).
2. Empty Service جديدة: `saudi-relative-strength`، تُنشر إليها محتويات هذا المجلد فقط.
3. في Variables لخدمة التطبيق أضيفي `DATABASE_URL` بالمرجع الداخلي لقاعدة السعودية الجديدة **وليس** قاعدة مصر. لا تنسخي بيانات الدخول إلى الملفات.
4. اختياري لكن موصى به: Volume لخدمة التطبيق مربوط بالمسار `/data`، ثم `DATA_DIR=/data` لحفظ CSV. الـVolume لا يحل محل قاعدة البيانات.
5. `SCAN_ADMIN_TOKEN` قيمة سرية طويلة لتشغيل `/api/scan` إداريًا، ولا تُرسَل إلى أي شخص. لا يحتوي الموقع العام على زر ينفّذ الفحص حفاظًا على موارد Railway. لبدء فحص بإعدادات معينة استخدمي طلب POST إداريًا أو شغلي الفاحص من جلسة CLI موثوقة.

## إعداد الجداول وتحميل البيانات
استخدمي اتصال القاعدة السعودية **فقط** في `DATABASE_URL`:

```powershell
py .\saudi_import_csv.py --schema-only
py .\saudi_import_csv.py --stocks .\saudi_stocks.csv --index .\saudi_tasi.csv
```

ملفات CSV أصلية موثوقة بالهيدر: `symbol,session_date,o,h,l,c,volume`. التواريخ `YYYY-MM-DD`، وملف المؤشر يجب أن يحتوي على `TASI` فقط. الرموز مثل `2222` (احفظيها كنص). لا تملئي الأيام الغائبة، واحتفظي بحجم التداول الصفري. حاسبة الأداء تستخدم High بعد الإشارة وحتى نهاية 52 أسبوعًا تقويميًا، وإغلاق الإشارة كأساس الشراء.

## تشغيل فحص عبر CLI موثوق
```powershell
py .\saudi_pgg_scan.py --rs 29 --ma-fast 18 --ma-slow 29 --start 2024-01-01 --output .\SAUDI_PGG_RESULTS
```

نطاق البنفسجي RPS < -0.21 مأخوذ من تجربة مصر؛ **لم يُثبت بعد على TASI** ويجب اختباره على السوق السعودي قبل اعتباره إشارة شراء موثوقة. إن لم تتوفر البيانات، لن تظهر إشارات افتراضية.

## النشر
```powershell
railway link
railway up --service saudi-relative-strength --environment production
```

**حماية**: قبل نشر رابط عام، فعّلي طبقة دخول/توثيق وصلاحيات المستخدمين؛ الخدمة العامة الحالية للعرض فقط ويُحظر تشغيل فحص إداري بدون `SCAN_ADMIN_TOKEN`. لا تنشري كلمات المرور أو ملف `.env`.
